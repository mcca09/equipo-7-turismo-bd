# RutasVenezuela - Equipo 7 (Turismo)

Base de datos relacional en PostgreSQL para la plataforma **RutasVenezuela** (UCAB).

## Estructura de ramas
- `main`: Rama principal (producción).
- `develop`: Rama de desarrollo e integración de los módulos del Equipo 7.
- Ramas por módulo (creadas a partir de `develop`):
  - `modulo-territorio-hitos`: Delimitación territorial, usuarios, hitos turísticos y credenciales digitales.
  - `app-territorio-hitos`: Interfaz móvil del módulo.
  - `reportes-territorio-hitos`: Reportes REP-01 y REP-02.
